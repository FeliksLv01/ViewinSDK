Android publishing update. The SDK capture API remains unchanged.

- Adds standard Maven Central publishing with PGP signatures and generated Dokka API documentation.
- Publishes `viewin-sdk`, `viewin-compose`, and the transitive `viewin-protocol` module under `io.github.felikslv01.viewin`.
- Validates independent View and Compose consumers on AGP 8.13.0 and 9.1.1, in Debug and minified Release.
- Archives signed Maven artifacts, metadata, source and documentation JARs, checksums, and license notices in GitHub Releases.
- Keeps the existing GitHub Maven `0.1.0` artifacts available for compatibility.

After this version is published to Maven Central, add `mavenCentral()` and choose one dependency:

```kotlin
implementation("io.github.felikslv01.viewin:viewin-sdk:0.1.1")
// Compose apps use this instead; it includes the base SDK:
// implementation("io.github.felikslv01.viewin:viewin-compose:0.1.1")
```

Requires Android API 29+. See the SDK documentation for compiler, framework-version, and capture limitations. The ZIP is a complete Maven repository backup; individual AAR / JAR attachments do not replace transitive dependency resolution.
